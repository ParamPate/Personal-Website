# Param's about-page prototype

React + Vite. Run `npm install`, then `npm run dev`. Validate with `npm test` and `npm run build`.

Only the introduction/about page is implemented. Pokémon PNG sprites are from [PokéAPI/sprites](https://github.com/PokeAPI/sprites); Pokémon characters belong to their respective owners. The trainer is an original simple SVG pixel drawing. No generated imagery is used.
